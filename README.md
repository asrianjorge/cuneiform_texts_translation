# Автоматическое распознавание и перевод клинописных текстов 

### План работы

0. __Выбор языка / корпуса клинописных текстов и постановка задачи:__ один язык или несколько, фотографии табличек / прорисовки / транслитерации, OCR отдельно или сразу OCR → перевод.
1. __Обзор существующих датасетов и методов распознавания клинописи:__ специализированные OCR-модели, CV-подходы, vision-language models. Сравнение качества и определение сложных случаев: повреждённые таблички, плохое освещение, разные стили письма и т. д.
2. __Подготовка датасета и baseline:__ унификация данных, разбиение train/val/test, обучение базовой модели распознавания знаков или последовательности знаков. Сравнение вариантов preprocessing — бинаризация, повышение контраста, сегментация и т. п.
3. __Исследование способов улучшения распознавания:__ современные архитектуры CV/VLM, transfer learning, аугментации. Отдельно проверить генерацию синтетических изображений клинописи и использование их для расширения обучающей выборки.
4. __Обучение и оценка итоговой OCR-модели. Проведение экспериментов и абляций:__ влияние preprocessing, синтетических данных, архитектуры и объёма данных. Анализ ошибок на разных типах текстов.
5. __Модуль перевода:__ преобразование распознанной клинописи в транслитерацию и/или естественный язык. Сравнение специализированных моделей и LLM, оценка влияния ошибок OCR на качество перевода.
6. __Объединение в единый pipeline:__ изображение таблички → распознанный текст → транслитерация → перевод. Создание простого интерфейса для демонстрации системы.
7. __Опционально:__ работа с особенно повреждёнными табличками — восстановление отсутствующих знаков по визуальному и языковому контексту; live/demo-тестирование на ранее не встречавшихся изображениях.
